# 本地视觉调优

## 当前默认配置

本地视觉服务优先使用可用的 NVIDIA CUDA GPU。默认模型为 `YOLO11s`，GPU 输入边长 `960`，分析帧率 `12 FPS`。RTX 3060 6GB 已完成验证；没有 CUDA 时会自动回退至 CPU，建议把输入边长改成 `640`。

服务每次启动时读取项目根目录 `.env`。复制 `.env.example` 为 `.env` 后可调整参数。

## 调整原则

- 人物框出现观众、替补或场边工作人员：提高 `COURTVISION_PLAYER_MIN_CONFIDENCE`，建议每次增加 `0.05`。
- 人物框漏掉远景球员：降低该阈值，或把 `COURTVISION_MODEL_SIZE` 从 `960` 提高到 `1088`；先确认显存可用。
- 篮球漏检：先把 `COURTVISION_BALL_MIN_CONFIDENCE` 降低到 `0.14`；系统仍会移除没有相邻帧运动支持的低置信候选。
- 篮球误检：把该阈值提高到 `0.22` 或 `0.25`。
- 轨迹编号频繁跳变：把 `COURTVISION_TRACK_MERGE_GAP_SECONDS` 从 `0.9` 增至 `1.1`。超过 `1.2` 容易把相邻球员错误合并。
- 画面卡顿或显存不足：先将输入边长降低为 `832`，再降低分析帧率到 `10`。

## 可靠性边界

当前模型是 COCO 通用模型，能提供人物和篮球候选，但没有训练“NBA 球员”“裁判”“观众”“球衣号码”等专用类别。系统只会在号码 OCR、比赛名单和多帧投票都满足条件后标注姓名；未满足条件时保持轨迹编号。要根本区分球员与裁判，需要引入或训练篮球专项检测模型。
